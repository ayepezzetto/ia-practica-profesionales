## Cómo usarlo

1. Elegí plataforma para la actividad.
2. Empezá con la práctica de prioridades.
3. Revisá el resultado antes de reutilizar el procedimiento.
4. Avanzá por proyectos, skills, RAG y conexiones.

El material es una primera versión. Las funciones concretas dependen del producto y plan. La skill debe adaptarse y validarse en la plataforma de destino. No incluye accesos ni credenciales.

## Publicación

La portada está en docs/index.html. Para GitHub Pages, seleccioná main y /docs como origen. Publicá únicamente material didáctico y ficticio.
