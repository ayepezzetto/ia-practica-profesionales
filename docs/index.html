Una rutina que ayuda

Probá primero la tarea. Si tu plataforma permite programarla, verificá horario y cancelación.

Primera práctica · 15 minutos

Usá estos pendientes ficticios: revisar una propuesta el martes, preparar una clase el jueves y pedir un presupuesto sin fecha.

Con estos pendientes, armá una tabla de tarea, próximo paso, duración estimada y fecha. Separá fechas dadas de estimaciones. Proponé un bloque de 30 minutos. No envíes mensajes ni modifiques mi calendario. Si falta un dato, marcá pendiente de confirmar.

Revisá: que no invente fechas, que reconozca información ausente y que el bloque no exceda 30 minutos.

Privacidad desde el primer ejercicio

Practicá con información ficticia. Compartí instrucciones, nunca contraseñas o accesos. Una skill sola no ejecuta tareas programadas; un MCP no garantiza seguridad.
